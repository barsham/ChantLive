## 1.1.70 - 31 July 2026

Clearer event-day logistics and more useful participant recovery.

### Improved

- Complete dashboard logistics: Organiser event cards now show the saved meeting point and arrival guidance alongside the venue and schedule for faster event-day checks. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- Dashboard event directions: Organisers can open directions to the saved venue and meeting point directly from an event card. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- Arrival-ready calendar invites: Participant calendar entries now preserve the meeting point, arrival guidance, directions, participant link, and event code in the selected language. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- Localized participant recovery checklist: A failed join now gives participants a short, translated checklist for checking the code, reopening the original link, and confirming availability with the organiser.

### Fixed

- Organiser-ready recovery details: Participants can copy the localized failure, checked code, and attempted link together, with a selectable on-screen fallback when clipboard access is blocked.
