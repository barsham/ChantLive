## 1.1.73 - 4 August 2026

A safe end-to-end workflow for turning a proven event into a fresh future draft.

### Added

- Repeat any event from the dashboard: Organisers can start a new edition from any draft, live, or ended event without exporting, importing, or rebuilding it by hand. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- Clear repeat-event choices: A focused dialog validates the new title and schedule while letting organisers choose whether to bring chants, logistics, and the support link forward. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- All-or-nothing event copying: Selected event content and timing are copied together in one server transaction so organisers never land in a half-built repeated event. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- Fresh participant access and live state: Every repeated event gets a new participant code and resets live status, the current chant, automation, participant activity, feedback, questions, polls, safety reports, and admin access. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- Review, rehearse, and invite handoff: The new event opens with a safety summary, copied-content receipt, fresh code, and direct next steps to review the plan and rehearse the participant view. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
