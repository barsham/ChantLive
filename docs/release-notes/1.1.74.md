## 1.1.74 - 5 August 2026

Opt-in offline participation for events where mobile signal cannot be trusted.

### Added

- Offline-capable participant app: A prepared ChantLive page can reopen its production app shell without a network connection, while API, authentication, and live Socket.IO responses are never cached.
- Save an event for weak signal: Participants can explicitly save the event currently on screen to their own device before entering a low-signal area.
- Latest verified chant after an offline reload: Prepared devices restore the most recently received event and chant when the live connection cannot be reached, and keep the saved copy current while online updates arrive.
- Clear offline safety and privacy controls: A prominent timestamped warning distinguishes saved information from live instructions, with reconnect and forget actions plus a clear device-only privacy explanation in every supported language.
- Organiser low-signal rehearsal workflow: The Command Center now provides a preparation link and three-step device rehearsal so organisers can verify their crowd fallback before the gathering starts.
