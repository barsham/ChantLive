## 1.1.77 - 8 August 2026

One accountable live operator can safely hand event control between organiser devices without conflicting participant updates.

### Added

- Automatic launch ownership: Going live assigns the launching organiser as the event's operator and clearly confirms which device owns live control. [GitHub issue #13](https://github.com/barsham/ChantLive/issues/13)
- Live control handoff desk: The Command Center identifies the operator and lets them hand control to another verified event admin or release it cleanly. [GitHub issue #13](https://github.com/barsham/ChantLive/issues/13)
- Server-protected live commands: Chants, announcements, polls, incidents, help resolution, timing, and event-ending commands now reject conflicting non-operator changes. [GitHub issue #13](https://github.com/barsham/ChantLive/issues/13)
- Read-only collaborator mode: Other admins can monitor live readiness and participant responses while risky controls stay visibly locked on their device. [GitHub issue #13](https://github.com/barsham/ChantLive/issues/13)
- Owner device-loss recovery: An event owner can explicitly take over after an operator device fails; durable status refresh and 44px participant display/recovery controls support mobile continuity. [GitHub issue #13](https://github.com/barsham/ChantLive/issues/13)
