## 1.1.62 - 24 July 2026

More forgiving participant joining and safer organiser event setup.

### Fixed

- Whole-invitation joining: Participants can paste a complete ChantLive invitation message and the join tool will extract its participant link automatically. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- Future-date protection: Event creation now blocks past dates and explains how to correct the schedule before an organiser continues. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)

### Improved

- Clearer invitation-paste guidance: The landing join form now explains that it accepts a whole invitation message, participant link, or short event code.
- Readable event code on QR handouts: The organiser QR panel now includes the short event code and link-first instructions so scanning remains optional. [GitHub issue #15](https://github.com/barsham/ChantLive/issues/15)
- Failed-code troubleshooting: Participant recovery screens now show the event code that was checked, in every supported interface language.
