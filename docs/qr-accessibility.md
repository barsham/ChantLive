# QR Accessibility Checklist

Use this checklist when sharing a ChantLive participant link at an event.

## Provide More Than the QR Code

- Print or display the full participant URL near the QR code.
- Keep the URL short enough to read aloud if the QR scan fails.
- Include a short instruction such as: "Open your camera, point it at the QR code, then tap the ChantLive link."
- Make sure event volunteers know where to find the participant URL.

## Make the Code Easier to Scan

- Use high contrast: dark QR code on a plain light background.
- Avoid placing QR codes over photos, gradients, or patterned backgrounds.
- Test the QR code on multiple phones before the event starts.
- Keep the code large enough for the expected viewing distance.
- Do not crop, stretch, or compress QR code images in messaging apps.

## Support Participants During the Event

- Keep at least one admin device open to the participant view as a reference.
- Have a fallback way to announce the current chant if network access is poor.
- Re-test the participant link after going live.
