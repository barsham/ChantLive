## Submission Steps

1. Search the directory for `ChantLive` immediately before submitting to avoid
   a duplicate.
2. Open `Add Project` from the directory navigation.
3. Enter the project name, live website, source repository, factual
   description, Australian location, and the closest available categories.
4. Do not claim that ChantLive is proven safe, secure, private, accessible, or
   reliable.
5. Preview the entry and submit it only after Barsham approves the wording.
6. Record the submission date, review status, listing URL, referrals, test
   starts, and actionable feedback in `docs/promotion-experiments.md`.

The current Airtable form does not expose its field labels to text-only web
research, so the exact field order may differ. The directory itself confirms
that projects are added through the official `Add Project` form.
