# ChantLive Seven-Minute Paired Test

This is a small practical test, not a request for promotion, endorsement, a
partnership, or a purchase. ChantLive is free and open source.

## What You Need

- Two people, or one person using two browsers or devices.
- About seven minutes.
- The live app: https://chantlive.online/

One person acts as the organizer. The other acts as a participant.

## The Test

### 1. Prepare a Session

The organizer creates a sample event called `Community Test` and adds three
short sample chants:

1. Welcome everyone
2. Together we can
3. Thank you for being here

Use harmless sample text that suits your community if these examples do not.

### 2. Join

The organizer shares the ordinary participant link.

The participant opens it without creating an account. A QR code is optional;
the test must also work using the ordinary link.

### 3. Run It

The organizer changes the current chant three times. The participant watches
for each update, then refreshes or briefly locks and unlocks the device.

### 4. Send Three Observations

Reply with short answers:

1. Where did either person hesitate or need an explanation?
2. What is the biggest reason you would not trust this at a real event?
3. What one change would make it more useful or accessible?

Please include the device, browser, or assistive technology used when it
affected the result. A few sentences are enough.

## Optional Stress Check

If time allows, try one of these:

- join after the session has already started;
- use keyboard-only navigation or a screen reader;
- zoom text to 200%;
- switch between Wi-Fi and mobile data;
- recover after closing and reopening the participant page; or
- try the flow without scanning a QR code.

## Source And Privacy

Source code: https://github.com/barsham/ChantLive

Do not use a real event name, real participant information, confidential
material, or sensitive chants for this test.
